<h1 align="center">
	Work In Progress
</h1>

### Uno Game Engine
Custom C++20 / DirectX 12 game engine focused on real-time rendering, rigid body physics simulation
and a path tracer relying on Monte-Carlo estimation, denoising and DLSS.<br/>
While not currently open source, a fork of the engine only including the path tracer can be found [here](https://github.com/edoardo911/Real-Time-Path-Tracer).

### [LLM Lair](https://github.com/edoardo911/LLMLair)
A CLI wrapper of llama.cpp that allows the customization and local inference of GGUF large language models.<br/>
In the future fine-tuning and agentic mode support will be added.

### [snAIke](https://github.com/edoardo911/snAIke)
A DQN machine learning model that lears to play the classic Snake game in a 9x9 grid.<br/>
The model is trained using reinforcement learning and can be used as a baseline for other RL projects.
